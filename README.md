INTRODUZIONE

GI Master Mind e' un gioco di memoria che consiste nel indovinare una combinazione segreta di colori. In questa release e' possibile sfidarsi con il proprio computer nel tentare di indovinare le 4 posizioni avendo a disposizione 8 colori. Non vi e' nessun limite sul numero di tentativi


USO

Per eseguire il gioco basterà effettuare il consueto doppio click sulla sua icona.

Il gioco è stato scritto in C++ e non richiede installazione.

Il gioco, una volta lanciato, aprirà la sua finestra principale.
